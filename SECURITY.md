# Security Policy

> **Audience:** Users and security researchers reporting a possible Reminder Buddy vulnerability.

## Supported Versions

Security fixes are provided for the latest published version only. Confirm the latest version on the [Releases page](https://github.com/sidharth096/reminder-buddy/releases/latest) before reporting or testing an issue.

## Report A Vulnerability

Do not open a public GitHub issue.

Email `sidharthtp096@gmail.com` with:

- A clear description of the vulnerability and its impact
- The affected Reminder Buddy version and Windows version
- Exact reproduction steps or a proof of concept
- Any suggested mitigation
- Whether the issue has been disclosed elsewhere

Do not include real user data, credentials, or destructive payloads. You should receive an acknowledgment within seven days. Please allow time for investigation and a release before public disclosure.

## Scope

Reminder Buddy stores reminder data locally in `%LOCALAPPDATA%\ReminderBuddy`. Reports involving the app, installer, online installation script, release artifacts, or update process are in scope. Social engineering, denial-of-service testing against GitHub, and reports that require physical access to an already unlocked computer are out of scope.
